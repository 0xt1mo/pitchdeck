## The cross-source insights (the real value)

These second-order theses emerge only by connecting *multiple* sources — none is a single
vendor's claim:

1. **The production gap is quadruple-sourced.** Databricks (19% deployed / 95% pilots
   fail), Camunda (71% using / 11% production / 40% scrapped by 2027 / 5% deliver
   revenue), Cisco (97% excited / **2% ready** — a 48× gap), Deepgram (80% run agents /
   21% satisfied). Four independent 2026 datasets, one 60–90pt chasm — and every one names
   the cause as **trust/governance, not model quality.**
2. **Three sources name the two-layer split without knowing Unicity exists.** Red Hat ("AI
   is not automation — decision engine vs. execution plane"), Camunda (the orchestrator
   "is not an agent"), HiveMQ ("enforcement at the infrastructure level, regardless of
   agent reasoning"). The architecture is **convergent industry structure**, not a novel
   claim — Unicity is the missing *cryptographic, portable* half of a split everyone runs.
3. **"Why now" is trust readiness, not model capability.** Morgan Stanley: 64% blame data-
   security unpreparedness for slow adoption. Deepgram: cost is *not* the barrier (38%);
   quality/trust (72%) and integration (65%/60%) are.
4. **The actor already changed, at machine volume.** Databricks/Neon telemetry: agents
   create 80% of databases and 97% of database branches, up from 0.1% two years ago.
   NVIDIA: 100:1 agents-to-humans. Gartner: F500 average <15 → 150,000+ agents by 2028.
5. **The payment rails are already machine-operated.** Money Movement 2.0 (Mar 2026):
   70–90% of stablecoin volume is *already* programmatic; 69,000 x402 agents / 165M txns;
   $7.5T/month on-chain past US ACH. This **inverts** the old "demand hasn't arrived"
   framing → *machine money is already the norm; the signer has no passport.*
6. **Multi-vendor mesh makes platform-native governance structurally impossible.**
   Databricks: 78% run 2+ LLM families, 59% run 3+, multi-agent orchestration is the #1
   use case. No single platform's native controls can be the universal proof.
7. **Every incumbent builds a chokepoint, none ships a proof.** Coinbase (LiteLLM gateway
   + self-hosted KMS), Securiti (Data Command Graph), Datadog (telemetry-to-a-human),
   Camunda (BPMN orchestrator). The white space is the negative space across all of them →
   **the one new slide.**
8. **The buyers spec'd the primitive.** Nexer/GS1: *"trust, not tech."* AP2 = *"the
   cryptographic security necessary for agents to make verifiable, autonomous purchases."*
9. **Governance is deal-velocity, not tax.** Databricks (12× / 6× / 7× in 9 months), Red
   Hat (Mutua Madrileña), Nexer EU AI Act guide — provable governance is the throughput
   gate, not the brake.
10. **Endpoint hardening is destroying after-the-fact evidence** → proof must be minted at
    action-time. Magnet Forensics: MDM blocks ~48% of investigations; mobile encryption
    limits 53.3%; cloud backups "are not a substitute."
